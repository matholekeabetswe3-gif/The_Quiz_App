# TheQuizApp

## Purpose 
TheQuizApp is an Android application built with Kotlin. The app tests users' knowledge through a multiple-choice quiz format, displaying questions one at a time and calculating the final score.
## Design Considerations
- **UI/UX**:   Used Material Design components and ConstraintLayout for a clean, responsive interface -
-  **Language**: Kotlin for concise, null-safe Android development
-  **Architecture**: Single-activity design with functions to handle quiz logic
-  **Data Handling**: Questions and answers stored in Kotlin data structures within the app
## Utilisation of GitHub and GitHub Actions
- **GitHub**: Used for version control and project submission. A `.gitignore` file was added to exclude IDE configuration files `.idea/`, build outputs `build/`, and local Gradle cache `.gradle/` from the repository. -
-  **GitHub Actions**: Not implemented for this submission as CI/CD was not required by the project scope.
## App Features
  1. **Start Screen**: Welcome screen with a button to begin the quiz
   2. **Question Display**: Shows one question with 3-4 multiple choice options.
   3. **Score Tracking**: Tracks correct answers and displays final score
   4. **Result Screen**: Shows final results with option to restart
